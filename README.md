# Paper AI

Ollamaを使って、論文PDFの翻訳と読解を支援するローカルアプリケーションです。

PDFから本文を取り出し、論文の構成を保ちながら日本語訳や要約を作成することを目指しています。翻訳文や要約はMarkdown形式で保存し、後から読み返したり編集したりできる形にします。

> 開発中です。現在利用できる機能や実行方法は、実装に合わせて更新します。

## 目指している機能

- 論文PDFからのテキスト抽出
- 論文の章や節に沿った分割処理
- Ollamaを使った英語論文の日本語翻訳
- 論文全体や各セクションの要約
- 翻訳と要約のMarkdown出力

## 使用予定のモデル

まずは翻訳用と論文読解用のモデルを分けて利用する予定です。軽量な汎用モデルも、比較や補助用途として試す候補にしています。

| 用途 | Ollamaモデル | 役割 |
| --- | --- | --- |
| 英語論文の日本語翻訳 | [`translategemma:12b`](https://ollama.com/library/translategemma) | 翻訳を担当 |
| 要約・論文の読解支援 | [`gemma4:12b`](https://ollama.com/library/gemma4) | 要点整理や内容の説明を担当 |
| 軽量な汎用処理・比較用 | [`qwen3.5:9b`](https://ollama.com/library/qwen3.5) | 他モデルとの比較や補助用途 |

モデルはOllamaから取得します。

    ollama pull translategemma:12b
    ollama pull gemma4:12b
    ollama pull qwen3.5:9b

モデルの役割や採用構成は、実際の論文で品質と処理速度を確認したうえで調整します。

## 処理の流れ

    論文PDF
      ↓
    テキスト抽出・セクション分割
      ├─ TranslateGemma → 日本語訳
      └─ Gemma 4 → 要約・論文の読解支援
      ↓
    Markdownファイル

論文全体を一度にモデルへ渡すのではなく、セクションごとに処理することで、長い論文を扱いやすくし、原文の構成を出力に反映することを目指しています。

## データの取り扱い

Ollamaをローカル環境で動かす構成では、PDFの内容をローカルのモデルで処理できます。Ollamaの接続先を外部サーバーに設定した場合は、送信した内容がそのサーバーで処理されます。接続先を確認してから利用してください。

## 注意事項

PDFの構造によっては、本文の抽出時に段組み、数式、表、脚注、図表のキャプションなどが正しく読み取られないことがあります。また、翻訳や要約には誤りや抜けが含まれる場合があります。研究や引用に使う際は、原文と照らし合わせて確認してください。
