# 設計

## 実装アプローチ

ルート `AGENTS.md` に、作業の進め方、実行環境の前提、変更・検証時の共通ルールを短く明確にまとめる。プロジェクト固有の情報がない項目は、推測で固定せず、必要になった段階でissueや既存資料から確認する方針とする。

実行環境欄には、ユーザー提供情報として、NVIDIA GeForce RTX 4060 Ti（16,380 MiB）、Driver Version 565.90、CUDA Version 12.7を現在の環境情報として記載する。`nvidia-smi` の CUDA Version 表示はドライバーが対応するCUDAの上限情報であり、ToolkitやPythonライブラリの導入状況を示すものとして書かない。

## 変更するファイル

- `AGENTS.md`: GitHub issueを確認して作業すること、Macでは実行できずGPU搭載Windows PCのWSL環境を対象にすること、作業時に守る共通指針を記載する。

## 指針に含める内容

- 作業開始時にissue本文、受け入れ条件、関連する既存実装・ドキュメントを読む。
- issueの範囲に沿って変更し、要件の曖昧さや前提の不足は推測せず明示する。
- 既存の構成・依存管理を尊重し、不要な依存追加や無関係な変更を避ける。
- 変更後は実行可能な確認を行い、実行環境の制約で確認できない場合はその理由と未確認事項を記録する。
- 秘密情報やローカル環境固有の設定をコミットしない。
- 実行環境欄のGPU情報と、依存ライブラリ側の対応状況を混同しない。

## 影響範囲

リポジトリでの今後の開発手順に影響する。アプリケーションコードや依存関係は変更しない。
