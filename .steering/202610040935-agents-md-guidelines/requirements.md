# 要求内容

## 目的

リポジトリで作業する人やエージェントが共通の進め方と実行環境の前提を理解できるよう、ルートの `AGENTS.md` を整備する。

## ユーザーストーリー

- 開発者として、実装前に対応するGitHub issueを確認し、issueの目的と受け入れ条件に沿って作業したい。
- 開発者として、Macでは実行できず、GPUを搭載したWindows PC上のWSL環境で実行するプロジェクトであることを明確にしたい。
- 開発者として、環境差による誤った実行・検証を避けるため、作業時の基本ルールも参照したい。

## 受け入れ条件

- `AGENTS.md` は日本語で記述する。
- GitHub issueを作業の起点とし、実装前に内容・受け入れ条件・関連情報を確認する方針を明記する。
- Macでは実行できないこと、GPUを搭載したWindows PCのWSL環境を実行対象とすることを明記する。
- 現在のリポジトリ構成とPythonプロジェクトであることに合わせ、変更範囲・依存関係・検証結果の記録など、再利用可能な開発上の指針を必要な範囲で追加する。
- ユーザー提供の `nvidia-smi` 出力と補足に基づき、現在のGPUとドライバー情報として記載する。
- CUDA Versionは `nvidia-smi` が表示した値として扱い、CUDA ToolkitやPyTorchのインストール済みバージョンと混同しない。
- PyTorch等の依存関係や具体的なセットアップ手順は、根拠が確認できない限り断定しない。

## 制約事項

- `.steering/`はGit管理対象としてコミットする。
- 現時点で `AGENTS.md` と `README.md` は空で、Pythonパッケージの依存関係も未定義である。
- GPU情報はユーザーにより現在の状態と一致すると確認されている。
- 実行環境の具体的な構築手順は、根拠が確認できない限りこの作業では規定しない。
- AGENTS.mdの変更は、ステアリング内容の確認後に行う。
