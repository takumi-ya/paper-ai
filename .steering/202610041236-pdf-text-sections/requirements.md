# 要求: PDF論文のテキスト抽出とセクション分割

## 概要

Issue #1 に基づき、テキストレイヤーを持つ論文PDFを読み込み、ページ単位と文書全体のテキストを抽出し、一般的な見出し構造からセクションごとの本文を返す。

## ユーザーストーリー

- 利用者として、PDF論文を入力し、後続の翻訳・要約処理で扱えるページ情報とセクション情報を得たい。
- 利用者として、ページ番号や繰り返しヘッダー／フッターの混入を可能な範囲で抑えたい。
- 利用者として、References相当の部分を本文翻訳から除外できる形で取得したい。

## 受け入れ条件

- PDFパスを受け取り、PDF全体のテキストとページ単位テキストを保持する。
- セクション名、本文、本文対象かどうかを構造化して返す。
- 番号付き・番号なし見出しや一般的な同義見出しを扱い、特定の会議・出版社テンプレートに依存しない。
- References/Bibliography相当のセクションを本文対象外として識別する。
- 反復するページヘッダー／フッターと単独ページ番号を保守的なヒューリスティックで除去する。
- PDF抽出とセクション検出を別モジュールに分ける。
- 正常系、複数の見出し表記、References除外、ページ／ノイズ処理、異常系を単体テストで確認する。

## 制約

- Python 3.12以上、PDFライブラリは PyMuPDF を採用する。
- OCR、図表画像解析、数式の厳密な復元、翻訳、要約、RAGは対象外。
- 実PDF複数件と2段組PDFでの目視確認はWindows/WSL環境で行う。本Mac環境では実行済みと扱わない。
